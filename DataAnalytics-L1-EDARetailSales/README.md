## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales patterns, customer demographics, product-category performance, and relationships between numerical variables.

## 🎯 Objectives

- Inspect and understand the dataset
- Perform descriptive statistical analysis
- Analyze monthly and quarterly sales trends
- Study customer age groups and gender distribution
- Analyze product-category sales
- Examine correlations between numerical variables
- Identify useful business insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

1. Dataset loading and initial inspection
2. Missing-value and duplicate checking
3. Descriptive statistics
4. Monthly sales trend
5. Quarterly sales trend
6. Customer age-group distribution
7. Gender distribution
8. Product-category analysis
9. Revenue by product category
10. Correlation heatmap
11. Average customer spending by gender

## 💡 Key Insights

The analysis examines sales trends, customer demographics, product-category performance, and purchasing behaviour to identify patterns that can support data-driven business decisions.

## 📁 Project Files

- `EDA_Retail_Sales.ipynb` – Complete analysis notebook
- `retail_sales_dataset.csv` – Dataset used for analysis

## 📌 Dataset Limitation

The dataset contains product categories but does not contain individual product names. Therefore, product analysis is performed at the product-category level.

## ✅ Conclusion

The EDA provides insights into customer characteristics, sales trends, product-category performance, and purchasing behaviour. These findings can support inventory planning, marketing analysis, and sales monitoring.
