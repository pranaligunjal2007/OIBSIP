# Data Cleaning and Preprocessing

## Objective
The objective of this task is to clean and preprocess a dataset by identifying and handling missing values, duplicate records, data quality issues, and outliers.

## Dataset
The dataset was intentionally prepared with data quality issues for performing data cleaning and preprocessing.

## Data Cleaning Steps

The following steps were performed:

1. Loaded and inspected the dataset.
2. Checked the number of rows and columns.
3. Identified missing values.
4. Checked for duplicate rows.
5. Checked data types and data quality.
6. Identified and analyzed outliers.
7. Applied appropriate outlier treatment.
8. Created a cleaned dataset.
9. Compared the dataset before and after cleaning.
10. Generated data quality and outlier treatment reports.

## Files

- `data_cleaning.ipynb` – Jupyter Notebook containing the complete data cleaning process.
- `messy_dataset.csv` – Original dataset containing data quality issues.
- `cleaned_dataset.csv` – Final cleaned dataset.
- `before_after_summary.csv` – Comparison of dataset before and after cleaning.
- `before_cleaning_quality_report.csv` – Data quality report before cleaning.
- `outlier_treatment_report.csv` – Report of outlier identification and treatment.
- `screenshots/` – Screenshots showing the cleaning process and results.

## Results

After cleaning:

- Rows: **891**
- Missing values: **0**
- Duplicate rows: **0**
- Data quality was checked after preprocessing.
- Outliers were identified and treated where required.

## Conclusion

The dataset was successfully cleaned and preprocessed. The final dataset is ready for further analysis and visualization.
